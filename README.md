|---------------------------------------------------Kafka Example Project---------------------------------------|
Это пример проекта на Spring Boot с использованием Apache Kafka для обмена сообщениями между продюсером и консьюмером.

|---------------------------------------------------Описание проекта------------------------------------------|
Проект демонстрирует простую архитектуру с двумя ключевыми компонентами:

MessageProducer — компонент, который отправляет сообщения (UserRegisteredEvent) в Kafka топик test-topic.

MessageListener — компонент, который слушает сообщения из Kafka топика test-topic и обрабатывает их.

|---------------------------------------------------Структура---------------------------------------------------|
DTO:
Класс UserRegisteredEvent описывает структуру сообщения — содержит userId и email.

KafkaProducerConfig:
Конфигурация Kafka-продюсера, задает параметры подключения к брокеру, сериализацию ключей и значений.

KafkaConsumerConfig:
Конфигурация Kafka-консьюмера, задает параметры подключения, десериализацию и группу консьюмера.

MessageProducer:
Spring-компонент, который через KafkaTemplate отправляет сообщения в Kafka.

MessageListener:
Spring-компонент с @KafkaListener, который слушает топик test-topic и обрабатывает полученные события.
